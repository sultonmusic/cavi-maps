# Управление картой Tajikistan Map

Карта: https://capline-tj-map.web.app  
Администратор: https://capline-tj-map-admin.web.app  
На основном домене также работает https://capline-tj-map.web.app/admin.

Логин **CaplineGroup-map**. Пароль — заданный владельцем при создании проекта. Пароль не включён в исходный код, сборку или этот документ. Вход проверяет Firebase Authentication; доступ к записи защищён правилами Firestore и идентификатором администратора.

## Карта редактора

Редактор работает на той же карте, что и пользователи: поворот и наклон двумя пальцами, объёмные дома. Нажатие по объекту редактора (организация, микрорайон, добавленное здание) выбирает именно его, а не улицу под ним.

## Улицы и микрорайоны

После входа откройте «Улицы», приблизьте карту и нажмите на дорогу или найдите её в списке. Измените название, выберите покрытие и нажмите «Сохранить». Для проектной улицы, состоящей из нескольких отрезков, включён выбор всей улицы: название и стиль применяются к её отрезкам. Вкладка «Районы» меняет названия четырёх зон.

| Вариант | Полосы | Вид на карте |
| --- | --- | --- |
| Исходное оформление | Из исходного слоя | Возврат к исходному виду дороги |
| 0 | Одна общая полоса для двух направлений | Узкий серый асфальт без осевой линии |
| 1 | Одна туда + одна обратно | Асфальт с осевой прерывистой линией |
| 2 | Две туда + две обратно | Более широкий асфальт с разделителями полос |

Стиль покрытия — оформление карты. Он не изменяет разрешённые направления проезда, ограничения поворотов или дорожный граф. Названия «Улица 1…209» и «1…4 микрорайон» — проектная нумерация с севера на юг, не официальный адресный реестр.

## Организации и отзывы

«Организации» → «Добавить»: заполните название, категорию, описание, адрес, телефон, email, сайт и часы работы. Положение можно указать нажатием на карту. Добавьте позиции меню с ценами в сомони. Переключатель «Опубликовано» определяет видимость организации пользователям, «Отзывы» — возможность оставить и читать отзывы.

Пользователь нажимает на организацию и открывает «Информация, меню и отзывы» в компактной карточке. Новый отзыв сначала попадает в раздел «Отзывы» администратора. Одобрение публикует его; отклонение скрывает. Оценки рассчитываются только по одобренным отзывам. Изменения данных, координат и публикации синхронизируются без перезагрузки при работающем интернете.

## Здания

«Здания» → «Добавить»: нажимайте по углам здания, замкните контур кнопкой завершения и сохраните. Вершины можно перетаскивать; сохранённые авторские здания можно переименовать, перерисовать или удалить. Это ручная разметка — необходимо знать действительное расположение и контур здания.

Автоматическое копирование домов из Google Maps в этой версии не выполнялось. Проверен открытый набор [Google Open Buildings](https://sites.research.google/gr/open-buildings/): в опубликованном перечне стран V3 Таджикистан отсутствует. Существующие здания из локальной исходной базы сохранены. Их редактирование в интерфейсе пока не включено; редактор управляет добавленными зданиями.

## Локальная папка и хранение

Запуск `START.cmd` открывает локальную карту с тем же Firebase и теми же актуальными правками. Интернет необходим для входа и синхронизации. Геометрия и маршруты находятся в папке; избранное хранится в браузере. Экспорт в админке скачивает JSON со всеми текущими правками; это резервная копия данных, а не автоматический импорт.

Для изолированной работы только на компьютере остановите текущий сервер, выполните `node scripts/setup-admin.mjs` (задаёт скрытый пароль), затем `node serve.mjs --local-data`. Если администратор уже настроен, повторная настройка не нужна; смена локального пароля: `node scripts/setup-admin.mjs --replace`. В этом режиме используется собственная база `data/edits.json` и SSE. Она не синхронизируется с Firebase. Локальный хеш пароля находится в `security/admin.json`; оба каталога закрыты от статической раздачи и исключены из ZIP.

## Разработка и публикация

Firebase-проект **Tajikistan Map**, ID `capline-tj-map`, создан на Spark. Firestore Standard, регион `asia-south1`, бесплатная база. Платное выставление счетов не подключалось. Сайты используют один проект и одну базу.

`public/runtime-config.json` содержит публичную конфигурацию Firebase и ID администратора, не секретный пароль. Изменение этого файла не даёт прав записи: их проверяет Firestore. `firestore.rules` закрывает запись для обычных клиентов, скрывает черновики и очередь модерации. `firestore.indexes.json` описывает индекс отзывов.

После правок: `npm ci`, `npm run check`, `npm run build`, затем `firebase deploy --project capline-tj-map`. Развёртывается только `dist`; серверные файлы, локальная база, исходники и секреты не публикуются. Скрипт `scripts/check-firebase.mjs` проверяет права и обновления двух независимых клиентов; пароль передаётся только переменной окружения `ATLAS_ADMIN_PASSWORD`. Временные тестовые данные удаляются.
