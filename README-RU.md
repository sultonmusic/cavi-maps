# Cavi Maps — карта Таджикистана

*by Capline Group*

Дважды нажмите **START.cmd**. Карта откроется в браузере. Оставьте окно запуска открытым; Ctrl+C останавливает сервер. Node.js 22+ уже установлен на этом компьютере. Готовая сборка находится в `dist`: установка npm для запуска не нужна.

На телефоне подключитесь к той же Wi-Fi сети и откройте адрес, который окно запуска показывает после «На телефоне». Компьютер должен оставаться включённым. Если Windows блокирует входящие подключения, разрешите Node.js в частной сети. Геолокация на телефоне по обычному HTTP может быть недоступна; начало маршрута можно выбрать касанием карты.

На узком экране кнопка «Поиск и места» открывает список, а «Карта» возвращает к карте. Два пальца меняют масштаб.

Нажмите на любое место карты: появится синий маркер без буквы и небольшая карточка. Нажатие на улицу распознаёт её по реальной геометрии и показывает название. Нажмите **«Маршрут»**. Введите **А** по названию доступного места, улице, адресу или координатам `40.6602, 70.3597`; также можно выбрать А на карте, из избранного или через «Моё местоположение». Для автомобиля показывается до трёх разных вариантов. Самый короткий выбирается автоматически. Когда подходящий путь только один, других вариантов не будет. Первый расчёт загружает дорожный граф и может занять около 20–30 секунд.

**«В путь»** сразу открывает маршрут и запрашивает GPS, когда он доступен. Отказ в разрешении не закрывает маршрут: остаётся **«Просмотр маршрута · без GPS»** с общей длиной, оценкой времени и ручным переключением шагов. Можно нажать «Без GPS» во время ожидания или «Включить GPS» позже. Движение в этом режиме не имитируется.

При доступном GPS показываются стрелка положения, следующая геометрическая подсказка, оставшееся расстояние, оценка времени и скорость, если её сообщает устройство. При отклонении от маршрута он пересчитывается. «Остановить» прекращает GPS-наблюдение. Время оценивается по 35 км/ч; пробки и ограничения поворотов в графе отсутствуют. Если Б находится вне дорожной сети, отдельно показывается расстояние от автомобильной дороги до Б.

Мобильная карточка занимает не более 42% высоты экрана, панель маршрута — не более 45%. Дополнительные сведения свёрнуты в «Подробнее» и «О маршруте».

Названия сохранены для 9 848 исходных дорог по всему Таджикистану. Безымянные улицы Шайдона пронумерованы **«Улица 1» — «Улица 209»** с севера на юг по самой северной точке улицы; при равенстве — с запада на восток. Продолжения одной улицы сохраняют общий номер: 209 улиц на 237 отрезках. Четыре проектные зоны получили названия **«1 микрорайон» — «4 микрорайон»** в том же порядке. Они отмечены **«Проектное название Cavi Maps»**, исходные названия, теги и геометрия не изменены. Проверка официальных публикаций: [STREET-SOURCES.md](STREET-SOURCES.md). Это проектная нумерация, а не официальный реестр.

На компьютере GPS работает через `localhost` с разрешением браузера. **Для GPS на телефоне используйте HTTPS.cmd** и настройте доверие к локальному сертификату по [GPS-HTTPS.md](GPS-HTTPS.md). Обычный HTTP-адрес компьютера подходит для карты и построения маршрутов, но браузеры телефона не разрешают GPS в таком контексте.

Перед поездкой дождитесь надписи **«Карта маршрута сохранена на устройстве»**: приложение сохранит дорожный граф и карту вдоль выбранного пути. Они доступны без связи с компьютером в том же браузере. Для новых, не сохранённых районов снова понадобится соединение. Не закрывайте вкладку во время навигации: работа GPS в фоне зависит от браузера и устройства.

Карта открывается на Шайдоне. Участок R-303 через посёлок оформлен серым асфальтом со светлой обочиной. При приближении появляются белые штрихи по центру. Это оформление по визуальному образцу; тип покрытия и дорожная разметка не подтверждены исходными данными. Геометрия пяти исходных участков, включая соединяющий мост, сохранена в `public/atlas-data/shaydon-r303-source.json`. Редактор поддерживает три варианта: **0** — одна общая полоса для обоих направлений, **1** — по одной полосе в каждую сторону, **2** — по две в каждую сторону. Ширина и разметка меняются на существующей геометрии; эти визуальные настройки не меняют ограничения проезда или расчёт времени маршрута.

Геометрия карты, поиск исходных мест, здания и маршруты используют файлы из этой папки. Вход администратора и синхронизация правок через Firebase требуют интернета. Избранное хранится отдельно в браузере каждого устройства. Внешние ссылки источников требуют интернета.

Во вкладке **«Профиль»** собраны избранное, адреса «Дом» и «Работа», недавние места и маршруты, настройки (способ передвижения, голосовые подсказки, город по умолчанию) и сохранение карты города для работы без интернета. Всё это хранится только в браузере этого устройства; учётная запись не нужна.

На телефоне карту можно установить как приложение: в меню браузера выберите «Установить приложение» или «На экран „Домой“». Значок и название **Cavi Maps** берутся из `public/manifest.webmanifest`.

Интерфейс на русском. Названия объектов берутся из `name:ru`, а при его отсутствии — из исходного названия. У части небольших населённых пунктов и улиц сохранены названия источника.

Карта рисуется движком MapLibre GL: её можно поворачивать двумя пальцами, наклонять, дома по всему Таджикистану показаны объёмом: контуры OpenStreetMap, а где их нет — Microsoft Global ML Building Footprints (ODbL). Дома страны лежат в `public/atlas-houses` и собираются командой `python scripts/build-country-houses.py <tajikistan.osm.pbf> <папка файлов Microsoft> public/atlas-houses`. Асфальт и полосы улиц по стране — из OpenStreetMap (`public/atlas-roads`, команда `python scripts/build-country-roads.py <tajikistan.osm.pbf> public/atlas-roads`): твёрдое покрытие по тегу surface, магистрали без тега считаются асфальтом, полосы из тегов lanes; правки администратора важнее. Остановки, светофоры, деревья, скамейки, фонтаны, памятники и флагштоки — тоже из OpenStreetMap (`public/atlas-things`, команда `python scripts/build-country-things.py <tajikistan.osm.pbf> public/atlas-things`), упрощённые объёмные модели повёрнуты к ближайшей улице. Пешеходные дорожки, тротуары, тропы и полевые дороги — `public/atlas-walks`, команда `python scripts/build-country-walks.py <tajikistan.osm.pbf> public/atlas-walks`. Участки собираются в браузере из локальных данных Cavi Maps — внешние тайловые серверы не используются. Сведения об исходных данных и лицензиях доступны по кнопке «О карте». Данные не являются собственной независимо собранной базой: © OpenStreetMap contributors, ODbL, выгрузка Geofabrik от 06.09.2026. Копия лицензии: `public/atlas-data/LICENSE.txt` и `dist/atlas-data/LICENSE.txt`.

Содержимое: 8 002 места и 6 440 домов Шайдона, 4 730 из них с номерами по улицам. 133 дома добавлены из выпуска Microsoft Global ML Building Footprints от 03.02.2026 командой `python scripts/add-shaydon-buildings.py <папка файлов Microsoft>`: существующие дома сохраняют свои номера и правки администратора, контуры на проезжей части отбрасываются. Полнота зависит от исходной базы. Маршруты приблизительные, без пробок и ограничений поворотов.

## Изменение исходного кода

`app/page.tsx` — интерфейс; `app/globals.css` — оформление и мобильная версия; `lib/atlas-gl.ts` — рисование карты; `public/route-worker.js` — маршрутизация; `public/` — локальные данные.

Для разработки: `npm ci`, затем `npm run dev`. Для обновления готовой сборки и списка офлайн-файлов: `npm run build`. Проверка типов: `npm run check`. Проверки: `node scripts/check-renderer.mjs`, `node scripts/check-map-edits.mjs`, `node scripts/check-routing.mjs --real`, `node --experimental-strip-types scripts/check-navigation.mjs`, `node scripts/check-offline.mjs`, `node scripts/check-travel.mjs`, `node scripts/check-brand.mjs`. Название и подпись платформы (Cavi Maps, by Capline Group) задаются в `lib/brand.mjs`, знак — в `components/cavi-mark.tsx`; значки приложения и `favicon.svg` перерисовывает `python scripts/make-app-icons.py`. Проектную нумерацию и привязку подписей к исходным улицам воспроизводит `python scripts/number-shaydon.py` без повторной обработки PBF. После создания новых улиц/зон скрипт запускается после `propose-street-names.py` и `propose-shaydon-districts.py`.

Карта также размещена в Firebase: https://capline-tj-map.web.app. Администратор: https://capline-tj-map-admin.web.app. Инструкция по редактированию, организациям, зданиям и локальной базе: [ADMIN-RU.md](ADMIN-RU.md).
