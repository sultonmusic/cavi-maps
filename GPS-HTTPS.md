# GPS на телефоне в локальной сети

На компьютере карта по `http://localhost:4173` может запрашивать геолокацию. На телефоне адрес вида `http://192.168…:4173` для GPS не подходит: браузеру нужен HTTPS с доверенным сертификатом и разрешение на местоположение. Обычный запуск `START.cmd` по-прежнему подходит для карты и выбора точек. [Требования браузера к watchPosition](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/watchPosition).

## Первый запуск HTTPS

1. На компьютере дважды нажмите `HTTPS.cmd`. Он создаёт сертификаты только в папке `security`, затем запускает карту на порту 4174. Если не хватает библиотеки Python, выполните указанную команду установки и запустите файл повторно. Для установки библиотеки нужен интернет; для последующих запусков — нет.
2. Передайте на свой телефон только файл `security/atlas-local-ca.crt`, например по USB. Это открытый сертификат локального центра доверия. Сверьте его отпечаток SHA-256 с напечатанным в окне запуска, если устройство показывает отпечаток. Файлы с `key` в имени остаются на компьютере.
3. Вручную установите этот сертификат как доверенный на своём телефоне. На Android найдите в настройках пункт установки сертификата CA (часто «Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат CA»; названия зависят от версии и производителя). На iPhone установите профиль сертификата, затем включите полное доверие в «Основные → Об этом устройстве → Доверие сертификатам». Корпоративное устройство может запрещать такую установку.
4. Подключите телефон и компьютер к одной Wi-Fi сети или точке доступа. На телефоне откройте **https-адрес**, который показывает окно запуска, например `https://192.168.1.10:4174`. Если адресов несколько, используйте Wi-Fi адрес компьютера. Должна открыться страница без предупреждения о сертификате; простое продолжение через предупреждение не заменяет доверие.
5. Включите местоположение телефона, откройте маршрут и нажмите «В путь». Разрешите доступ к местоположению в браузере. Держите страницу открытой; работа GPS в фоне и на заблокированном экране зависит от браузера и ОС.

HTTPS.cmd **не устанавливает сертификаты в систему**, не меняет доверие Windows или телефона и не размещает карту в интернете. При желании проверить HTTPS на самом компьютере сертификат CA также нужно вручную установить в доверенное хранилище; для обычного `localhost:4173` этот шаг не требуется. Оставьте окно сервера открытым. Остановка: Ctrl+C. Порт можно изменить переменной `PORT`.

## Если соединение не работает

- Перед выходом из сети дождитесь сохранения выбранного маршрута на устройстве. Сохранённая карта вдоль маршрута и дорожный граф позволяют продолжать навигацию без подключения к компьютеру. Несохранённые участки карты требуют связи с компьютером. Браузер может очистить локальный кэш; это не установка отдельного мобильного приложения. Держите страницу открытой.
- После смены сети или IP компьютера перезапустите `HTTPS.cmd`: сертификат сервера обновится с новым адресом. Локальный CA останется прежним, повторно устанавливать его не нужно. Срок сертификата сервера — 90 дней; запуск обновляет его заранее.
- Если адрес не открывается, проверьте одинаковую сеть и разрешение Node.js в частной сети брандмауэра Windows. В изолированной гостевой Wi-Fi сети устройства могут не видеть друг друга.
- Если карта открывается, но местоположения нет, проверьте разрешения браузера и ОС, доверие сертификату и сигнал GPS. На компьютере положение может определяться по сети приблизительно.

Папка `security` содержит личные ключи этого экземпляра Atlas. Она исключена из Git и не должна попадать в общий ZIP или в `dist/public`. На другом компьютере сертификаты создаются заново. После завершения использования локального HTTPS удалите установленный «Atlas Local CA» из доверенных сертификатов своего устройства. [Описание доверия локальным сертификатам](https://web.dev/articles/how-to-use-local-https).
